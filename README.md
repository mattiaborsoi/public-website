# borsoi.co.uk

Personal portfolio site — [borsoi.co.uk](https://borsoi.co.uk)

Built with Next.js (static export) and deployed to Cloudflare Pages.

## Dev

```bash
npm install
npm run dev
```

## Deploy

Cloudflare Pages builds automatically on push to `main`:
- Build command: `npm run build`
- Output directory: `out`
